# 类型：管理员速查手册（`admin-quick-reference`）

## 解决什么问题

让有管理权限的人按"我遇到什么问题"快速定位操作，而不是从头读一本手册。

## 默认参数

| scope 默认 | 受众默认 | 落点后缀 |
|---|---|---|
| `project` | `operator` | 无 |

`module` / `subsystem` 不适用，最低 `project`。

## base 章节

1. 系统定位（一句话 + 架构图）
2. 设计理念（3–7 条，每条说明解决了什么问题）
3. 读者路径图（第一次部署 / 日常运营 / 遇到问题）
4. 按管理域分章（全部 Q&A）
5. 附录（权限对比、场景方案、配置索引，按需）

`project` 追加：财务与计费细则、审计与合规、权限对比。

## 与运营手册的区别

| 维度 | 运营手册 | 管理员速查 |
|---|---|---|
| 组织 | 按业务模块 | 按管理域 + 问句索引 |
| 入口 | 顺序阅读 | 按问题跳转 |
| 深度 | 操作 + 影响 | 操作 + 判据 + 回滚 |
| 危险标注 | 三级 | 三级 + 不可逆操作清单 |

## 各章要点

**路径图**：Mermaid flowchart，三类读者各一条路径，指向具体章节。

**Q&A**：所有子标题为问句（如何… / 什么是… / 为什么…）。答案含操作步骤、危险等级、业务影响、验证方式。

**权限对比**：功能 | 角色 A | 角色 B | …，横向矩阵。

**场景方案**：按"我遇到的问题"索引到解决步骤，每场景含痛点、组合方案图、配置表。

## 写作规范

- 同运营手册：无技术术语，术语表引用 `dimensions/operations-manual.md`
- 每章开头保留前置依赖链路与影响矩阵
- 不可逆操作单独汇总成清单

## 常见失败

| 失败 | 纠正 |
|---|---|
| 写成运营手册 | 改为问句索引 + 路径图 |
| 只写步骤不写判据 | 补"怎么判断成功/失败" |
| 权限表缺失 | 补横向矩阵 |
| 危险操作散落 | 汇总成清单 |

## 边界

- 面向普通运营人员 → `operations-manual`
- 配置项实现 → `lld`
- 告警处置 → `slo`
