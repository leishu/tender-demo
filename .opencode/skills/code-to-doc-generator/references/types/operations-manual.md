# 类型：运营手册（`operations-manual`）

## 解决什么问题

让不懂技术的运营与管理人员能独立完成配置、判断影响、规避风险。

## 默认参数

| scope 默认 | 受众默认 | 落点后缀 |
|---|---|---|
| `project` | `operator` | 无 |

`module` / `subsystem` 不适用，最低 `project`。

## base 章节

1. 关于本手册
   - 系统是什么（定位图）
   - 核心设计理念（表：理念 | 含义 | 对操作的影响）
   - 如何使用本手册（读者路径图）
2. 按业务模块分章（每章固定两节开头 + Q&A）
3. 附录（按需）

`project` 追加：权限矩阵、故障应急预案、术语表。

## 每章结构

```
🔗 前置依赖链路
📊 影响追踪矩阵
Q：如何……？
  功能说明（1 句）
  💡 设计背景（推断不出则省略）
  操作步骤 + 流程图
  系统状态影响
  ⚠️ 危险 / 📌 注意
  业务规则
  关联影响表
  🔧 已知局限
```

分析维度见 `dimensions/operations-manual.md`。

## 写作规范

- 问答式标题，全部用问句
- 不含技术术语，替换表只在 `dimensions/operations-manual.md` 定义
- 危险操作必须标注等级与后果
- 已知局限有则写，上限 5 条，不设下限

## 常见失败

| 失败 | 纠正 |
|---|---|
| 按代码模块分章 | 按业务功能分章 |
| 影响矩阵第四列写"影响计费" | 补策略名与机制 |
| 前置链路漏副作用 | 写清缺失时的意外结果 |
| 术语未替换 | 按替换表逐条检查 |

## 边界

- 接口与实现 → `lld`
- 监控指标 → `slo`
